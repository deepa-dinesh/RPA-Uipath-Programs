# UiPath Folder and File Activities

## Description
This project demonstrates folder and file management automation using UiPath Studio. It performs basic operations such as creating folders, checking file existence, copying, moving, and deleting files.

## Activities Used
- **Create Folder:** Creates a new folder.
- **Path Exists:** Checks whether a folder or file exists.
- **Copy File:** Copies files from one location to another.
- **Move File:** Moves files between folders.
- **Delete File:** Deletes the specified file.

## Workflow
1. Specify the folder path.
2. Create a new folder.
3. Check whether the required file exists.
4. Copy or move the file to the destination folder.
5. Delete the file if required.

## Tools Used
- UiPath Studio
- RPA
- Sequence Workflow

## Objective
To automate basic file and folder management tasks using UiPath activities and understand how RPA simplifies repetitive operations.

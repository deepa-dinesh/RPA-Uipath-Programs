# UiPath Input Dialog, Message Box and If Activities

## Description
This project demonstrates basic Robotic Process Automation (RPA) activities using UiPath Studio. It uses Input Dialog to get input from the user, Message Box to display messages, and If activity to perform conditional operations based on the entered value.

## Activities Used
- **Input Dialog:** Accepts input from the user.
- **Message Box:** Displays messages on the screen.
- **If Activity:** Checks a condition and executes the appropriate action.

## Workflow
1. Display an Input Dialog to enter a value.
2. Store the entered value in a variable.
3. Use the If activity to check the entered value.
4. Display a success or error message using Message Box.

## Tools Used
- UiPath Studio
- RPA
- Sequence Workflow

## Objective
To understand basic UiPath activities and implement user input handling and conditional decision-making through automation.
